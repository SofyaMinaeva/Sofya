# Анализатор оценки 360

Приложение принимает:
1. JSON-отчет 360 по сотруднику (оценки по компетенциям от разных групп);
2. Текстовые ответы респондентов (свободные комментарии).

На выходе формирует **отчет для руководителя**, который можно использовать для:
- кадровых решений (продвижение, сохранение в роли, PIP);
- формирования плана развития сотрудника на 90 дней.

## Логика работы

Сначала приложение определяет целевой формат отчета для руководителя:
- паспорт оценки;
- executive summary;
- таблица компетенций с разрезом по группам и разбросом оценок;
- кадровая рекомендация с обоснованием;
- план развития (действия, метрики, сроки).

Далее анализирует числовые оценки + текстовые комментарии и собирает итоговый Markdown-отчет.

## Запуск

```bash
python3 app.py --report examples/sample_report.json --answers examples/sample_answers.txt --output manager_report.md
```

Только вывод формата отчета:

```bash
python3 app.py --report examples/sample_report.json --answers examples/sample_answers.txt --format-only
```

## Формат входного JSON

Поддерживаются 2 схемы внутри `competencies`:

1. Через `ratings`:
```json
{
  "name": "Лидерство",
  "ratings": [
    {"group": "self", "score": 4.5},
    {"group": "manager", "score": 4.2}
  ]
}
```

2. Через `scores`:
```json
{
  "name": "Коммуникация",
  "scores": {
    "self": 4.0,
    "manager": 3.8,
    "peers": 3.6
  }
}
```

Группы: `self`, `manager`, `peers`, `reports`, `external`.
